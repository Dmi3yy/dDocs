# Using Evolution CMS

[Evolution CMS](../README.md) / Using Evolution CMS

This section explains core manager workflows for current Evolution CMS. It
covers the built-in product surface only. Installed Extras expose their own
package documentation in dDocs.

## Scope

These pages document the built-in manager workflows that are stable enough for
the English baseline. Screenshots, role-specific walkthroughs, and per-setting
field help belong in follow-up pages after each manager screen is validated
against current code.
