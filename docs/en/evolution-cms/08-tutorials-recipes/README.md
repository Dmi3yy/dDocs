# Tutorials And Recipes

They should be practical, small, and easy to test.

## Recipe Rules

- Prefer current project, package, route, and model surfaces.
- Keep installed Extra behavior in the package's own docs.
- Do not copy old snippets, old components, or legacy install paths as current
  recommendations.
- Link to reference pages when a recipe depends on a broader contract.
