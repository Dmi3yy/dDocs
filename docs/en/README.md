# Documentation Hub

This English documentation hub separates dDocs module documentation from
Evolution CMS product documentation.

| Area | Open |
| --- | --- |
| dDocs | [dDocs Documentation](ddocs/README.md) |
| Evolution CMS | [Evolution CMS Documentation](evolution-cms/README.md) |

Use [dDocs Documentation](ddocs/README.md) for the module, package documentation
standards, file indexing, rendering, authoring, and contribution rules. Use
[Evolution CMS Documentation](evolution-cms/README.md) for current product
documentation built from the Evolution CMS codebase and installer.
