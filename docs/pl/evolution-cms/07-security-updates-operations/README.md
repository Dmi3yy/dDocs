# Bezpieczeństwo, aktualizacje i operacje

diagnostyka instalacji, odświeżanie pamięci podręcznej, uprawnienia, adresy URL, dostęp do plików,
aktualizacje i kontrole bezpieczeństwa produkcji.

## Bieżący zakres

Pierwszy przebieg dodaje praktyczną listę kontrolną rozwiązywania problemów. Wzmocnienie bezpieczeństwa,
strony dotyczące przepływu pracy aktualizacji, tworzenia kopii zapasowych/przywracania, wdrażania i monitorowania są kontynuowane
działają i muszą zostać sprawdzone pod kątem aktualnego kodu przed publikacją.
