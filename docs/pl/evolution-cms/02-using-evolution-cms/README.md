# Używanie Evolution CMS

[Evolution CMS](../README.md) / Korzystanie z Evolution CMS

W tej sekcji opisano przepływy pracy głównego menedżera dla bieżącego Evolution CMS. To
obejmuje wyłącznie wbudowaną powierzchnię produktu. Zainstalowano Extras, eksponując własne
dokumentacja pakietu w dDocs.

## Zakres

Te strony dokumentują wbudowane workflow Managera, które są wystarczająco
stabilne dla bieżącego baseline. Zrzuty ekranu, role-specific walkthroughs i
field-level help dla ustawień powinny trafić do kolejnych stron po sprawdzeniu
każdego Manager screen względem aktualnego kodu.
