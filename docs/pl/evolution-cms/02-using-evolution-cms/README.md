# Używanie Evolution CMS

[Evolution CMS](../README.md) / Korzystanie z Evolution CMS

W tej sekcji opisano przepływy pracy głównego menedżera dla bieżącego Evolution CMS. To
obejmuje wyłącznie wbudowaną powierzchnię produktu. Zainstalowano Extras, eksponując własne
dokumentacja pakietu w dDocs.

## Strony

| Strona | Cel |
| --- | --- |
| [Resources i drzewo dokumentów](resources-and-document-tree.md) | Twórz, organizuj, publikuj, przeszukuj zasoby i rozwiązuj problemy. |
| [Elementy](elements.md) | Pracuj z szablonami, Template Variables, fragmentami, fragmentami, wtyczkami i modułami. |
| [Ustawienia, uprawnienia i pliki](settings-permissions-and-files.md) | Skonfiguruj ustawienia systemowe, przyjazne adresy URL, grupy dostępu, przeglądarkę plików, przesyłanie i uprawnienia menedżera. |

## Zakres

Strony te dokumentują wbudowane przepływy pracy menedżera, które są wystarczająco stabilne
podstawowa wersja angielska. Zrzuty ekranu, instrukcje dotyczące poszczególnych ról i ustawienia
pomoc terenowa będzie umieszczana na kolejnych stronach po zatwierdzeniu każdego ekranu menedżera
względem obowiązującego kodeksu.
