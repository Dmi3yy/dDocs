# Rozwój

[Evolution CMS](../README.md) / Rozwój

W tej sekcji opisano bieżące środowisko wykonawcze Evolution CMS z bazy kodu
na zewnątrz: układ projektu, rdzeń wykonawczy, powierzchnie menedżera, punkty rozszerzeń,
granice pakietów, testy i warstwy kompatybilności.

## Bieżący zakres

Pierwszą stroną rozwojową jest mapa źródłowa. Szczegółowe API, model, zdarzenie, usługa,
i strony referencyjne bazy danych stanowią odrębne prace uzupełniające i muszą zostać zatwierdzone
z aktualnym kodem przed publikacją.
