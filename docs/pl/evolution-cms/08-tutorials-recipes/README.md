# Poradniki i przepisy

[Evolution CMS](../README.md) / Poradniki i przepisy

Przepisy przedstawiają aktualne, potwierdzone kodem wzorce budowania przy użyciu Evolution CMS.
Powinny być praktyczne, małe i łatwe do przetestowania.

| [Formularze z trasami niestandardowymi](forms-with-custom-routes.md) | Obsługuj żądania formularzy frontonu za pośrednictwem bieżących pomocników routingu i odpowiedzi. |
| [Wzorce zapytań o zawartość witryny](sitecontent-query-patterns.md) | Zapytaj o zasoby, Template Variables, znaczniki i struktury drzewiaste z bieżących zakresów modelu. |

## Zasady przepisów

- Preferuj bieżący projekt, pakiet, trasę i powierzchnie modelu.
- Zachowaj zainstalowane zachowanie Extra we własnych dokumentach pakietu.
- Nie kopiuj starych fragmentów, starych komponentów ani starszych ścieżek instalacji jako aktualnych
  zalecenia.
- Link do stron referencyjnych, gdy przepis jest zależny od szerszej umowy.
