## Granica

To odniesienie opisuje sam Evolution CMS: środowisko wykonawcze, menedżer, parser,
ustawienia, uprawnienia, zdarzenia, modele i powierzchnie instalacyjne/operacyjne.
Zainstalowane Extras pojawiają się jako oddzielne źródła dDocs i powinny zachować własne
podręczniki użytkownika i programisty.
