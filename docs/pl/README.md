# Centrum dokumentacji

To centrum dokumentacji oddziela dokumentację modułu dDocs od dokumentacji
produktu Evolution CMS.

| Sekcja | Otwórz |
| --- | --- |
| Evolution CMS | [Dokumentacja Evolution CMS](evolution-cms/README.md) |
| dDocs | [Dokumentacja dDocs](ddocs/README.md) |

Użyj [Dokumentacji dDocs](ddocs/README.md), aby poznać moduł, standardy
dokumentacji pakietów, indeksowanie plików, renderowanie, tworzenie treści i zasady
współtworzenia. [Dokumentacja Evolution CMS](evolution-cms/README.md) opisuje
aktualny produkt na podstawie kodu Evolution CMS i instalatora.
