# Tutoriels et recettes

[Evolution CMS](../README.md) / Tutoriels et recettes

Les recettes montrent les modèles actuels et validés par le code pour la construction avec Evolution CMS.
Ils doivent être pratiques, petits et faciles à tester.

| Pages | Objectif |

## Règles de recette

- Préférer les surfaces actuelles du projet, du package, de l'itinéraire et du modèle.
- Conserver le comportement Extra installé dans la documentation du package.
- Ne copiez pas les anciens extraits de code, les anciens composants ou les anciens chemins d'installation comme étant actuels.
  recommandations.
- Lien vers des pages de référence lorsqu'une recette dépend d'un contrat plus large.
