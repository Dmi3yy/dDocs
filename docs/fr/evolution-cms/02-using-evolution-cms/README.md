# Utilisation de Evolution CMS

[Evolution CMS](../README.md) / Utilisation de Evolution CMS

Cette section explique les flux de travail du gestionnaire principal pour le Evolution CMS actuel. Il
couvre uniquement la surface intégrée du produit. Les Extras installés exposent leurs propres
documentation du package dans dDocs.

## Portée

Ces pages documentent les workflows Manager integres qui sont assez stables
pour la baseline actuelle. Les captures d'ecran, role-specific walkthroughs et
field-level help pour les reglages appartiennent aux pages de suivi, apres
validation de chaque Manager screen contre le code actuel.
