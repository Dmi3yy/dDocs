# Centre de documentation

Ce centre de documentation français sépare la documentation du module dDocs de
la documentation produit Evolution CMS.

| Zone | Ouvrir |
| --- | --- |
| dDocs | [Documentation dDocs](ddocs/README.md) |
| Evolution CMS | [Documentation Evolution CMS](evolution-cms/README.md) |

Utilisez la [documentation dDocs](ddocs/README.md) pour le module, les standards
de documentation des packages, l'indexation de fichiers, le rendu, l'authoring
et les règles de contribution. Utilisez la
[documentation Evolution CMS](evolution-cms/README.md) pour la documentation
produit actuelle construite depuis la base de code Evolution CMS et l'installer.
