# Центр документації

Цей український центр документації розділяє документацію модуля dDocs і
документацію продукту Evolution CMS.

| Розділ | Відкрити |
| --- | --- |
| dDocs | [Документація dDocs](ddocs/README.md) |
| Evolution CMS | [Документація Evolution CMS](evolution-cms/README.md) |

Використовуйте [документацію dDocs](ddocs/README.md) для модуля, стандартів
документації пакетів, файлового індексування, рендерингу, авторингу та правил
участі. Використовуйте [документацію Evolution CMS](evolution-cms/README.md)
для поточної документації продукту, побудованої з кодової бази Evolution CMS та
інсталятора.
