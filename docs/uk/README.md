# Центр документації

Цей центр документації англійською мовою відокремлює документацію модуля dDocs від
Evolution CMS документація продукту.

| Площа | Відкрити |
| --- | --- |
| dDocs | [Документація dDocs](ddocs/README.md) |
| Evolution CMS | [Документація Evolution CMS](evolution-cms/README.md) |

Використовуйте [Документацію dDocs](ddocs/README.md) для модуля, документацію пакета
стандарти, індексування файлів, візуалізація, створення та правила внесення. використання
[Evolution CMS Документація](evolution-cms/README.md) для поточного продукту
документація, створена з кодової бази Evolution CMS та інсталятора.
