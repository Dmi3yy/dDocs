# Підручники та рецепти

[Evolution CMS](../README.md) / Підручники та рецепти

Рецепти показують поточні, перевірені кодом шаблони для побудови за допомогою Evolution CMS.
Вони мають бути практичними, маленькими та легкими для перевірки.

## Сторінок

| Сторінка | Призначення |
| --- | --- |
| [Форми зі спеціальними маршрутами] (forms-with-custom-routes.md) | Обробляйте запити зовнішніх форм за допомогою поточних помічників маршрутизації та відповідей. |
| [Шаблони запитів вмісту сайту] (sitecontent-query-patterns.md) | Ресурси запитів, Template Variables, теги та деревоподібні структури з поточних областей дії моделі. |

## Правила рецептів

- Віддавайте перевагу поточному проекту, пакету, маршруту та модельним поверхням.
— Збереження встановленої поведінки Extra у власних документах пакета.
- Не копіюйте старі фрагменти, старі компоненти або застарілі шляхи встановлення як поточні
  рекомендації.
- Посилання на довідкові сторінки, коли рецепт залежить від ширшого контракту.
