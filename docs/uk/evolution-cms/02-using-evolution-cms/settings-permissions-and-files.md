# Налаштування, дозволи та файли

[Назад](elements.md) / [Вгору](README.md) / [Далі](../04-development/project-structure.md)

Цей посібник охоплює основні поверхні конфігурації менеджера: системні налаштування, дружні
URL-адреси, доступ до файлів, завантаження, пошук, ролі, дозволи та групи веб-доступу.

## Налаштування системи

Сторінка менеджера налаштувань системи захищена дозволом і може бути заблокована на час
інший користувач менеджера редагує його. Поточні вкладки налаштувань включають:

| Вкладка | Загальне використання |
| --- | --- |
| Загальні | Стандартні параметри сайту, параметри публікації, параметри кешу, параметри пошуку, поведінка індексу меню, шаблони та налаштування часу. |
| Дружні URL-адреси | Режим URL-адреси, суфікс/префікс, поведінка папок, суворі URL-адреси та поведінка псевдонімів. |
| Інтерфейс | Manager мова, тема, вибір редактора та параметри інтерфейсу. |
| Безпека | Пароль і налаштування безпеки менеджера. |
| Файловий браузер | Resource базовий шлях браузера та очищення імені завантаженого файлу. |
| Файл Manager | Шлях до файлового менеджера, дозволені списки завантажень, дозволені списки зображень/медіа та розмір завантаження. |
| Шаблони пошти | Налаштування шаблону електронної пошти Manager. |

Після зміни параметрів, які впливають на вихід, шляхи, URL-адреси, завантаження, кеш або
поведінку менеджера, оновити кеш і перевірити відповідний робочий процес.

## Дружні URL-адреси

Дружні URL-адреси вимагають:

1. Evolution CMS зручні налаштування URL-адреси ввімкнено.
2. Дійсні псевдоніми ресурсів.
3. Правила перезапису веб-сервера для проекту.
4. Оновлення кешу після змін.

Якщо точні URL-адреси не розпізнаються, скористайтеся пошуком менеджера за URL-адресою та перевірте ресурс
публікується, не видаляється і не блокується правилами доступу.

## Файли та завантаження

Переглядач файлів і поведінка завантаження залежать як від налаштувань Evolution CMS, так і від
дозволи файлової системи.

перевірити:

- шлях до файлового менеджера;
- базовий каталог браузера ресурсу;
- дозволені розширення файлу/зображення/медіа;
- налаштування розміру завантаження;
- PHP та обмеження завантаження на веб-сервер;
- дозволи на читання/запис каталогу.

## Ролі та дозволи Manager

Manager ролі та дозволи контролюють, до чого мають доступ користувачі менеджера. Коли користувач
не вдається відкрити екран, перевірте:

1. Роль користувача.
2. Дозвіл, який вимагає сторінка менеджера.
3. Чи заблоковано ресурс або елемент.
4. Чи прихована дія правилами доступу менеджера.

## Дозволи веб-доступу

Дозволи веб-доступу використовують групи користувачів і групи документів. Сторінка менеджера може
створювати, перейменовувати, видаляти та з’єднувати ці групи.

Використовуйте дозволи на доступ до Інтернету, коли відвідувачі сайту мають бачити лише певні захищені
ресурси. Якщо функцію вимкнено, на сторінці менеджера з’явиться попередження
управління групою.

## Пошук

Пошук Manager може знаходити ресурси за ідентифікатором, текстовими полями, точною URL-адресою, шаблоном і
значення Template Variable. Використовуйте його для випадків підтримки, де розташовано дерево
невідомий або ресурс прихований, видалений, неопублікований або захищений.

## Межа документації пакета

Документи основного менеджера описують вбудовану поведінку Evolution CMS. Встановлено Extras
відображаються як окремі джерела документації в dDocs. Якщо екран менеджера належить
до пакета, відкрийте документи цього пакета замість того, щоб очікувати, що це зробить документація продукту
дублюйте його посібник.
