# Елементи

[Назад](resources-and-document-tree.md) / [Вгору](README.md) / [Далі](settings-permissions-and-files.md)

Керування елементами – це область менеджера для шаблонів, Template Variables,
шматки, фрагменти, плагіни та модулі. Поточний керуючий код організовує їх як
на контролері Resources.

## Типи елементів

| Елемент | Використовуйте це для |
| --- | --- |
| Шаблон | Макет сторінки та структура виведення ресурсу. |
| Template Variable | Спеціальні поля, додані до шаблонів і збережені для кожного ресурсу. |
| Chunk | Багаторазова розмітка або фрагменти тексту. |
| Snippet | PHP-підтримувана логіка, яка повертає вихідні дані. |
| Plugin | Код розширення, керований подіями. |
| Module | Manager на стороні інструменту або екрана програми. |

## Робота з шаблонами

Створюйте або редагуйте шаблони, коли ресурсу потрібен макет або інший набір
Template Variables. Шаблон можна вибрати, заблокувати, категоризувати та зв’язати
до TVs.

Під час зміни шаблону:

1. Збережіть шаблон.
2. Огляд призначеного Template Variables.
3. Оновіть кеш, якщо вивід не зміниться.
4. Перевірте ресурси, які використовують шаблон.

## Робота з Template Variables

Template Variables визначте структуровані поля, які відображаються на ресурсах за допомогою
призначені шаблони. TVs має тип, заголовок, категорію, елементи/параметри,
режим відображення, текст за замовчуванням і правила доступу до ролі/шаблону.

Використовуйте TVs для даних вмісту, якими редактори мають керувати окремо від основних
поле вмісту ресурсу.

## Робота з Chunks і Snippets

Chunks – це багаторазові блоки тексту або розмітки. Snippets — це логічні блоки з підтримкою PHP.
Обидва можна вмикати, вимикати, дублювати, видаляти, блокувати та класифікувати з
менеджер.

Використовуйте фрагменти для повторної розмітки. Використовуйте фрагменти, коли результат потребує логіки виконання.

## Робота з Plugins і подіями

Plugins підключаються до іменованих подій і запускаються, коли їх викликає середовище виконання
події. Порядок Plugin контролюється пріоритетом події. Використовуйте плагіни для життєвого циклу
хуки, такі як збереження документа, парсер, менеджер, кеш, файловий браузер і користувач
події.

Перегляньте [Довідник про події](../10-reference/events.md), перш ніж додавати або змінювати
підключення події плагіна.

## Робота з Modules

Modules — це інструменти на стороні менеджера. Вони можуть мати код модуля, файли ресурсів,
спільні параметри, залежності та дії запуску/редагування. Встановлені модулі пакетів можуть
також мати пакетну документацію в dDocs.

Не копіюйте посібник модуля пакета в це дерево документів продукту. Відкрийте
джерело пакета в dDocs, якщо функція належить встановленому Extra.
