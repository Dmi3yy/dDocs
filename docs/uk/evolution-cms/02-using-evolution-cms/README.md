# Використання Evolution CMS

[Evolution CMS](../README.md) / Використання Evolution CMS

У цьому розділі пояснюється основні робочі процеси менеджера для поточного Evolution CMS. Це
покриває лише вбудовану поверхню продукту. Встановлений Extras виставляють свої власні
пакет документації в dDocs.

## Сторінок

| Сторінка | Призначення |
| --- | --- |
| [Resources і дерево документів](resources-and-document-tree.md) | Створюйте, упорядковуйте, публікуйте, шукайте та вирішуйте ресурси. |
| [Елементи](elements.md) | Працюйте з шаблонами, Template Variables, шматками, фрагментами, плагінами та модулями. |
| [Параметри, дозволи та файли](settings-permissions-and-files.md) | Налаштуйте параметри системи, дружні URL-адреси, групи доступу, перегляд файлів, завантаження та дозволи менеджера. |

## Сфера дії

Ці сторінки документують вбудовані робочі процеси Manager, які достатньо
стабільні для поточного baseline. Скріншоти, role-specific walkthroughs і
field-level help для окремих налаштувань мають додаватися в наступних
сторінках після перевірки кожного Manager screen за актуальним кодом.
