# Resources і дерево документів

[Назад](README.md) / [Вгору](README.md) / [Далі](elements.md)

Resources – це вузли вмісту, показані в дереві документів менеджера. Вони є
зберігається моделлю `SiteContent` і може представляти сторінки, папки, посилання або
інші типи вмісту залежно від їхніх полів.

## Створіть Resource

1. Відкрийте дерево документів менеджера.
2. Виберіть батьківське розташування.
3. Створіть новий ресурс або посилання з дерева або елементів керування діями менеджера.
4. Введіть назву сторінки, псевдонім, шаблон, вміст, налаштування меню та опублікуйте
   стан.
5. Збережіть ресурс.
6. Оновіть кеш сайту, якщо зміни не видно відразу.

## Редагувати вміст

Відкрийте ресурс із дерева та оновіть поля вмісту. Форма ресурсу
може містити поля Template Variable, якщо вибраному шаблону призначено TVs.

Важливі поля ресурсів включають:| Площа поля | Чому це важливо |
| --- | --- |
| Заголовок і заголовок меню | Використовується в дереві менеджера, меню та помічниках виводу. |
| Псевдонім | Використовується дружніми URL-адресами, якщо ввімкнено. |
| Батьківський та індекс меню | Керуйте розташуванням дерева та порядком меню. |
| Шаблон | Керує доступним макетом і Template Variables. |
| Опубліковано/видалено стан | Контролює, чи доступний ресурс для відвідувачів сайту. |
| Прапори з можливістю пошуку/кешування | Впливає на роботу пошуку та кешу. |
| Прапори приватного веб/менеджера | Впливають на правила доступу. |

## Організуйте дерево

Використовуйте дії дерева для переміщення, дублювання, видалення, відновлення, публікації та скасування публікації
ресурси. Операції переміщення викликають поточний потік переміщення менеджера та запускають переміщення
події. Видалити зазвичай позначає ресурс як видалений; порожній кошик видаляє видаляє
ресурси.

Якщо зміни дерева не видно, оновіть дерево та очистіть кеш.

## Пошук Resources

Поверхня пошуку менеджера може шукати поля ресурсів, точні ідентифікатори, точні URL-адреси,
фільтри шаблонів і значення Template Variable. Пошук точної URL-адреси використовує поточну
дружні налаштування URL-адреси та вирішення псевдонімів.

Використовуйте пошук, коли:

- ресурс захований глибоко в дереві;
- відомий псевдонім або URL-адреса, але ні ідентифікатор ресурсу;
- потрібно знайти значення Template Variable;
- потрібно перевірити стан видалених/неопублікованих.

## Примітки щодо зручної URL-адреси

Дружні URL-адреси залежать як від налаштувань Evolution CMS, так і від перезапису веб-сервера
правил. Якщо збережений псевдонім не працює:

1. Перевірте налаштування `friendly_urls`.
2. Перевірте параметри суфікса, префікса, папки та суворої URL-адреси.
3. Перевірте правила перезапису на веб-сервері.
4. Оновіть кеш сайту.
5. Переконайтеся, що цільовий ресурс опубліковано, а не видалено.

Для детальнішої перевірки операцій див
[Усунення несправностей] (../07-security-updates-operations/troubleshooting.md).
