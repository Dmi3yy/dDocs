# Навігація по документації

[Назад](source-inventory.md) / [Вгору](../README.md) / [Далі](documentation-source-policy.md)

Документація Evolution CMS використовує невелику граматику навігації, щоб читачі могли рухатися
через розділ, не покладаючись лише на ліве дерево.

## Типи навігації

| Тип посилання | Призначення | Приклад |
| --- | --- |
| Структурні | Перейдіть по дереву документації. | `Back`, `Up`, `Next` |
| Розділ дітей | Показати сторінки, які належать до розділу. | Таблиця в `README.md` |
| Семантичний | З’єднайте споріднені поняття або вихідні області. | `Related`, `See Also` |

## Структурні зв'язки

Використовуйте цю форму вгорі багатосторінкових розділів:

```text
# Page Title

[Back](previous.md) / [Up](README.md) / [Next](next.md)

Short reader-focused opening paragraph.

## Task Or Reference Section

...

## Related

- [Relevant page](other-page.md)
```

Якщо структурного сусіда не існує, пропустіть це посилання замість того, щоб винаходити a
мета.

## Розділ Цільові сторінки

Сторінки розділу `README.md` мають бути невеликими порталами. Вони повинні включати:

- один короткий абзац про розділ;
- таблиця дочірніх сторінок;
- поточний обсяг розділу;
- посилання на відповідні розділи лише за потреби.

## Довідкові сторінки джерела

Довідкові сторінки джерела можуть включати вихідні таблиці, списки команд, списки моделей,
таблиці конфігурації та статус перевірки. Вони не повинні включати приватні
шляхи файлової системи, умови внутрішнього планування або згенеровані метадані аналізу.

## Extras Посилання

Не дублюйте встановлену документацію Extras у продукті Evolution CMS
документи Посилання на документи на рівні пакета, якщо підтримуваний пакет володіє деталями.
