# Core Composer Reference

[Назад](configuration-runtime.md) / [Вгору](../README.md) / [Далі](legacy-compatibility.md)

Evolution CMS використовує файл Composer рівня проекту та основний файл Composer. The
основний файл Composer є основною межею залежності середовища виконання для встановленого
Проект Evolution CMS.

## Composer Файли

| Файл | Відповідальність |
| --- | --- |
| `composer.json` | Метадані проекту/кореневого пакета, базова лінія PHP, мінімальні розширення платформи та сценарій аналізу проекту. |
| `core/composer.json` | Основні залежності середовища виконання, правила автозавантаження, конфігурація плагіна Composer, сценарії виявлення пакетів та інструменти тестування. |
| `core/custom/composer.json` | Спеціальну для проекту точку розширення об’єднано за допомогою основного плагіна злиття Composer, якщо він присутній. |

Кореневий файл Composer описує пакет проекту. Залежність часу виконання
графік живе під `core/composer.json`.

## Метадані пакета виконання

| Поле | Поточне значення |

## Composer Об’єднати Plugin

Основна конфігурація Composer використовує `wikimedia/composer-merge-plugin` для включення:

```text
custom/composer.json
```Поведінка злиття:

| Варіант | Значення |
| --- | --- |
| `recurse` | `true` |
| `replace` | `true` |
| `merge-dev` | `false` |
| `merge-extra` | `true` |
| `merge-scripts` | `false` |

Використовуйте `core/custom/composer.json` для пакетів на рівні проекту замість редагування
безпосередньо файл середовища виконання Composer.

## Правила автозавантаження

| Тип автозавантаження | Записи |
| --- | --- |
| ПСР-4 | `EvolutionCMS\\` до `src/`, `Database\\Seeders\\` до `database/seeders/` |
| Карта класу | `database/migrations/` |
| Файли | Помічники основних дій, допоміжні функції, функції мосту Laravel, помічники вузлів, помічники попереднього завантаження, помічники процесора та утиліти. |
| Dev PSR-4 | `Tests\\` до `tests/` |

Список автозавантаження файлів зберігає застарілі функції помічника/дій, доступні в
сучасний час виконання.

## Composer Скрипти

| Сценарій | Призначення |
| --- | --- |
| `sync-replace` | Запускає помічник синхронізації заміни версії. |
| `test` | Проводить тести на шкідників. |
| `optimize` | Встановлює робочі залежності та створює дамп оптимізованого авторитетного автозавантаження. |
| `optimize-dev` | Встановлює залежності розробників і створює дамп оптимізованого авторитетного автозавантаження. |
| `upd` | Синхронізує версії для заміни та оновлює файл блокування. |
| `pre-install-cmd` | Запускає замінну синхронізацію перед встановленням. |
| `pre-update-cmd` | Запускає замінну синхронізацію перед оновленням. |
| `post-autoload-dump` | Працює `php artisan package:discover`. |

Виявлення пакетів є частиною генерації автозавантаження. Якщо постачальники послуг або
метадані пакета не оновлювати, запустити дамп автозавантаження Composer і перевірити пакет
результат відкриття.

## Dev Tooling

Основні залежності розробника включають:

| Пакет | Призначення |
| --- | --- |
| `pestphp/pest` | Тестовий бігун. |
| `mockery/mockery` | Випробування дублів. |
| `roave/security-advisories` | Блокує відомі вразливі версії залежностей. |

Файл кореневого проекту Composer також містить сценарій аналізу PHPStan для
рівень проекту.

## Правило документації

Під час документування встановлення пакета, вимог Composer або послуги
виявлення провайдера, вкажіть, яка межа Composer використовується: кореневий проект,
core runtime або `core/custom/composer.json`.
