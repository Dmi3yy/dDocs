# Вихідний інвентар

[Назад](../01-getting-started/installation.md) / [Вгору](../README.md) / [Далі](documentation-navigation.md)

Це посилання записує поточні вихідні поверхні, які повинні живити Evolution
Документація продукту CMS.

## Поточні джерела коду

| Поверхня | Використання документації |
| --- | --- |
| Корінь еволюції | Файли входу проекту, кореневі метадані Composer, загальнодоступний `index.php`, зразок конфігурації та рівень проекту README. |
| `core/` | Завантажувальна програма, середовище виконання Composer, конфігурація, кеш середовища, міграції бази даних, засівки, тести, сховище та точка входу Artisan. |
| `core/src/` | Основні служби, парсер, постачальники, моделі, контролери, проміжне програмне забезпечення, фасади, застарілі адаптери, класи підтримки та команди консолі. |
| `manager/` | Manager точка входу, маршрутизація дій, перегляди, процесори, включення, медіа та поведінка інтерфейсу користувача менеджера. |
| `install/` | Застарілий веб-інсталятор, сценарій встановлення CLI, ресурси встановлення, функції налаштування та заглушки встановлення. |
| `assets/` | Збірні модулі, плагіни, фрагменти, ресурси менеджера та ресурси під час встановлення. |
| `views/` | Заповнювачі рівня публічного перегляду проекту. |
| Пакет автономного інсталятора | Поточний рекомендований порядок встановлення та поведінка команд `evo`. |
| Встановлено Extras | Документи на рівні пакетів виявляються окремо за допомогою dDocs і не повинні дублюватися тут. |
| Архів старих документів | Лише застарілий довідковий матеріал після перевірки на поточний код. |
| Перевірені рекомендації | Майбутні рецепти лише після перевірки поточного коду. |

## Поточні сигнали часу виконання

| Сигнал | Примітки |
| --- | --- |
| PHP базовий рівень | Поточне ядро ​​та інсталятор потребують PHP `^8.3`. |
| Каркасний шар | Core використовує компоненти Illuminate 12 і поверхні Symfony Console/Process. |
| Manager маршрутизація | Manager запитує маршрут через один обробник дій та ідентифікатори дій. |
| Рівень консолі | Core надає команди Artisan для кешу, переглядів, пакетів, попередніх налаштувань, маршрутів, планування, оновлень сайту, перекладів, оновлень дерева, міграцій, засівачів, Tailwind і системних завдань. |
| Рівень даних | Core має моделі Eloquent для ресурсів, елементів, користувачів, дозволів, налаштувань, журналів подій, стану планувальника/працівника та даних дерева таблиці закриття. |
| Тести | Поточне ядро ​​має тести Pest для встановлення, керування, оновлення, системних завдань, утиліт підтримки та поведінки сумісності. |

## Невиконана документація

Базовий рівень англійською мовою охоплює вимоги, інсталяція спочатку,
довідник інсталятора CLI, основні концепції, робочі процеси основного менеджера, проект
структура, довідкові карти розробника, завантажувальна програма конфігурації/виконання, ядро
Composer, сумісність із застарілими версіями, команди встановленого проекту Artisan, система
налаштування/за замовчуванням, ролі та дозволи, Blade/відтворення шаблону, класичний
теги синтаксичного аналізатора, два перевірені рецепти, політика джерела, правила навігації та
усунення несправностей першої лінії.

| Розрив | Запланована публічна сторінка |
| --- | --- |
| Повна класика API і DB API | `06-api-and-integrations/` і `10-reference/` після перевірки на рівні методу |
| Довідка щодо налаштувань інтерфейсу користувача по полях | Розширте [Довідник із параметрів системи] (system-settings.md) після перевірки кожної мітки вкладки менеджера та збережіть процесор |
| Контракти корисного навантаження подій | Розширення [Посилання на події] (events.md) після перевірки кожного сайту виклику `invokeEvent` |
| Навігація по документації | [Навігація документацією] (documentation-navigation.md) |
| Більше найкращих рецептів | `08-tutorials-recipes/` після перевірки поточного коду |
| Локальні переклади | Тримайте локалізовані дзеркала синхронізованими з перевіреною англійською базовою лінією |
