# CLI Довідка

[Назад](../07-security-updates-operations/troubleshooting.md) / [Вгору](../README.md) / [Далі](source-inventory.md)

Ця сторінка є короткою довідкою для поточного командного рядка Evolution CMS
монтажні поверхні. Використовуйте [Встановлення] (../01-getting-started/installation.md)
для керованого процесу встановлення.

## Команди інсталятора

| Команда | Призначення |
| --- | --- |
| `evo install [dir] [flags]` | Встановити проект. Пропустіть `dir` у режимі TUI, щоб вибрати його інтерактивно. |
| `evo self-install` | Завантажте та встановіть двійковий файл інсталятора поруч із завантажувачем PHP. |
| `evo self-update` | Оновіть двійковий файл інсталятора з останнього доступного випуску. |
| `evo system-status` | Роздрукуйте стан системи JSON для діагностики інсталятора. |
| `evo version` | Роздрукуйте версію інсталятора. |

## Встановити прапорці

| Прапор | Значення |
| --- | --- |
| `-f`, `--force` | Встановити, навіть якщо цільовий каталог уже існує або виглядає як існуючий проект. |
| `--branch=<name>` | Встановіть Evolution CMS із певної гілки Git замість останнього сумісного випуску. |
| `--preset=<spec>` | Застосуйте попередні налаштування рівня проекту після основного встановлення. |
| `--db-type=<driver>` | Драйвер бази даних: `mysql`, `pgsql`, `sqlite` або `sqlsrv`. |
| `--db-host=<host>` | Хост бази даних для встановлення не SQLite. |
| `--db-port=<port>` | Порт бази даних. Якщо пропущено, програма встановлення використовує драйвер за замовчуванням, коли це можливо. |
| `--db-name=<name>` | Ім’я бази даних або ім’я файлу бази даних SQLite. |
| `--db-user=<user>` | Ім’я користувача бази даних для встановлення не SQLite. |
| `--db-password=<password>` | Пароль бази даних для встановлення не SQLite. |
| `--admin-username=<name>` | Початкове ім'я користувача адміністратора менеджера. |
| `--admin-email=<email>` | Початкова електронна адреса адміністратора менеджера. |
| `--admin-password=<password>` | Початковий пароль адміністратора менеджера. У режимі CLI він має містити принаймні 6 символів. |
| `--admin-directory=<dir>` | Manager назва каталогу. За замовчуванням `manager` у режимі CLI. |
| `--language=<locale>` | Мова встановлення, наприклад `en` або `uk`. |
| `--github-pat=<token>` | Маркер GitHub для запитів API і уникнення обмеження швидкості. |
| `--github_pat=<token>` | Альтернативний варіант написання маркера GitHub. |
| `--extras=<list>` | Розділені комами Extras для встановлення після налаштування. |
| `--log` | Записати вихідні дані журналу встановлення до `log.md`. |
| `--cli` | Запуск у неінтерактивному режимі CLI. |
| `--quiet` | Зменшити вихід CLI до попереджень і помилок. |
| `--composer-clear-cache` | Очистіть кеш Composer перед встановленням залежностей. |
| `--composer-update` | Під час налаштування використовуйте `composer update` замість `composer install`. |

## CLI Необхідні значення режиму

Режим CLI не ставить запитань. Надайте принаймні:

```bash
evo install demo \
  --cli \
  --db-type=sqlite \
  --db-name=database.sqlite \
  --admin-email=admin@example.com \
  --admin-password=change-me
```Якщо пропущено в режимі CLI, інсталятор за замовчуванням:

| Значення | За замовчуванням |
| --- | --- |
| Ім'я користувача адміністратора | `admin` |
| Каталог Manager | `manager` |
| Мова | `en` |
| Попереднє налаштування | `evolution` |
| Не-SQLite хост | `localhost` |
| Не користувач SQLite | `root` |

## Попередньо встановлені характеристики

| Специфікація | Резолюція |
| --- | --- |
| `evolution` | Встановлення тільки ядра; немає попереднього налаштування рівня проекту. |
| `default` | Загальнодоступне сховище налаштувань за умовчанням. |
| `evolution-cms-presets/default` | GitHub репозиторій у загальнодоступній організації пресетів. |
| `owner/repository` | Репозиторій GitHub. |
| Git URL | Використовуйте надану URL-адресу сховища безпосередньо. |
| Місцевий шлях | Використовуйте локальну попередньо встановлену перевірку та збережіть її як джерело. |
| `spec@ref` або `spec#ref` | Використовуйте певну гілку, тег або посилання. |

## Extras Синтаксис

| Синтаксис | Значення |
| --- | --- |
| `--extras=sTask,sSeo` | Встановіть керований Extras за назвою пакета. |
| `--extras=sTask@dev-main` | Встановіть керований Extra із явним обмеженням версії або розгалуження. |
| `--extras=legacy-store:84@1.12.2` | Встановіть пакет Legacy Store за ідентифікатором каталогу та версією. |

Документація Extras належить пакету. Після встановлення dDocs має виявити
документацію файлової системи кожного пакета та відобразіть її в дереві документації.

## Поля стану системи

`evo system-status` повертає JSON із загальним статусом і індивідуальними перевірками.
Поточні перевірки включають:

- операційна система;
- версія PHP;
- наявність Composer;
- PDO і драйвери бази даних;
- JSON, MySQLi, mbstring, cURL;
- Підтримка зображень GD або Imagick;
- дисковий простір;
- обмеження пам'яті.

Попередження означають, що встановлення все ще може тривати залежно від вибраної бази даних
або функція. Помилки означають, що в середовищі відсутній необхідний базовий рівень.
