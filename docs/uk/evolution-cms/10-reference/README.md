# Довідка

[Evolution CMS](../README.md) / Довід

Цей розділ є поверхнею пошуку для поточних контрактів виконання Evolution CMS.
Спочатку він написаний із поточного коду й уникає посібників із пакунків для встановлених
Extras.

## Межа

Це посилання описує сам Evolution CMS: середовище виконання, менеджер, парсер,
налаштування, дозволи, події, моделі та поверхні встановлення/роботи.
Встановлені Extras відображаються як окремі джерела dDocs і повинні зберігати власні
посібники користувача та розробника.
