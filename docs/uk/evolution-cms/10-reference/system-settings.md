# Довідка про налаштування системи

[Назад](artisan-and-manager-actions.md) / [Вгору](../README.md) / [Далі](roles-and-permissions.md)

Evolution CMS зберігає параметри часу виконання та менеджера на рівні системних параметрів.
Значення за замовчуванням для нової інсталяції визначаються заводськими налаштуваннями ядра
і можуть бути змінені через екран налаштувань системи менеджера, коли поточний
користувач менеджера має дозвіл на редагування налаштувань.

## Manager вкладки

| Вкладка | Область налаштувань |
| --- | --- |
| Загальні | Стандартні параметри сайту, публікація, параметри кешу за умовчанням, поведінка дерева, шаблони, журналювання, дати та відстеження відвідувачів. |
| Дружні URL-адреси | Дружній режим URL-адреси, суфікси, псевдоніми, сувора поведінка URL-адреси та поведінка URL-адреси папки. |
| Інтерфейс | Manager мова, тема, макет меню, розмір дерева, редактори, вигляд входу та кнопки інтерфейсу користувача. |
| Безпека | Спроби входу, тривалість сеансу, captcha, перевірка реферера, хешування пароля, політика оцінювання та доступність сайту. |
| Файл Manager | Корінь файлового менеджера, дозволені списки розширень завантаження, розмір завантаження, дозволи на файли та папки. |
| Файловий браузер | Resource Корінь браузера, налаштування зміни розміру зображення, приховані файли, мініатюри, очищення імен файлів і режим браузера. |
| Шаблони пошти | Відправник, транспортування пошти, налаштування SMTP, шаблони реєстрації та нагадування пароля. |

Plugins може додати HTML до вкладок налаштувань через рендер системних налаштувань
події, перелічені в [Довідкові відомості про події] (events.md).

## Правило документації

Під час документування налаштування включайте поточне значення за замовчуванням лише після перевірки
заводські налаштування або інсталяцію початкового шляху. Якщо проект перевизначає налаштування через
бази даних або середовища, задокументувати перевизначення в проектній документації, а не
у цьому посиланні на продукт.
