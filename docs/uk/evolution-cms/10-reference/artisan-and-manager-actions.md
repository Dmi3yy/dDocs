# Дії  Artisan і Manager

[Назад](events.md) / [Вгору](../README.md) / [Далі](source-inventory.md)

На цій сторінці відображаються поточні команди та поверхні дій менеджера. Це початок
пункт для детальнішої довідки про команди та документації робочого процесу менеджера.

## Artisan Команди

| Площа | Команди |
| --- | --- |
| Кеш і перегляди | `cache:clear-full`, очистити скомпільований кеш, очистити перегляди. |
| Пакети | `package:discover`, `package:create`, `package:installrequire`, `package:removerequire`, `package:installautoload`, `package:runconsoles`, `extras`. |
| Попередні налаштування | `preset:apply`, `preset:install`. |
| Списки та діагностика | `doc:list`, `template:list`, `tv:list`, `deprecated:list`, список маршрутів. |
| Планування | список розкладу та команди запуску розкладу. |
| Системні завдання | планувальник серцебиття та робочі команди завдань. |
| Сайт/час виконання | оновлення сайту, оновлення дерева, синхронізація перекладів, публікація постачальника, збірка Tailwind. |

Використовуйте [Довідник CLI](cli-reference.md) для окремої команди інсталятора `evo`
поверхні та [Artisan Commands Reference](artisan-commands.md) для повного
командна поверхня встановленого проекту. Ця сторінка є компактною картою, яка поєднує
команди з поверхнями дій менеджера.

## Manager Джерела дії

Дії Manager не є єдиним сучасним файлом маршруту. Поточна поведінка керівника
вирішується з кількох поверхонь:

| Поверхня | Відповідальність |
| --- | --- |
| `ManagerTheme` | Вирішує дію активного менеджера та контролера. |
| `core/factory/actionlist.php` | Застаріла карта ідентифікатора дії та метадані дії. |
| `core/src/Controllers/` | Контролери поточної сторінки менеджера. |
| `manager/actions/` | Застарілі та динамічні обробники дій. |
| `manager/processors/` | Зміна процесорів збереження/видалення/публікації/налаштувань/кешу. |
| `manager/views/` | Blade перегляди та кнопки дій. |
| Модель масивів `managerActionsMap` | Загальні ідентифікатори дій для редагування, збереження, видалення, дублювання, увімкнення, вимкнення, сортування, запуску та пов’язаних дій моделі. |

## Загальні моделі дій

| Область моделі | Загальні дії |
| --- | --- |
| Шаблони | новий, редагувати, зберегти, видалити, дублювати. |
| Template Variables | новий, редагувати, зберегти, видалити, дублювати, сортувати. |
| Chunks | новий, редагувати, зберегти, увімкнути, вимкнути, видалити, дублювати. |
| Snippets | новий, редагувати, зберегти, увімкнути, вимкнути, видалити, дублювати. |
| Plugins | новий, редагувати, зберегти, увімкнути, вимкнути, видалити, дублювати, сортувати, очистити. |
| Modules | новий, редагувати, зберегти, увімкнути, вимкнути, видалити, дублювати, запустити, залежність. |
| Resources | створювати, редагувати, зберігати, переміщувати, дублювати, публікувати, скасувати публікацію, видаляти, відновлювати, очищати кошик. |

## Правило документації

Під час документування дії менеджера перевірте всі три рівні:

- ідентифікатор дії або модель карти дії;
- контролер/дія/процесор, який обробляє запит;
- представлення менеджера, яке відкриває дію для користувача.

Не розглядайте старі назви дій як поточну поведінку, якщо вони все ще не вирішуються
поточне середовище виконання менеджера.
