# Довідник моделей

[Назад](parser-tags.md) / [Вгору](../README.md) / [Далі](events.md)

Це посилання відображає поточну поверхню моделі Eloquent. Це сторінка пошуку для
автори та розробники документації; це не повне посилання на схему.

## Моделі вмісту та дерева

| Модель | Відповідальність |
| --- | --- |
| `SiteContent` | Resource/вузли дерева документів, поля вмісту, прапорці публікації/видалення/кешу/пошуку, батьківські/начірні зв’язки, групи документів, значення шаблону та поведінка дерева таблиці закриття. |
| `ClosureTable` | Попередник дерева/нащадок/глибина зберігання для операцій ієрархії ресурсів. |
| `DocumentGroup` | Рядки зв’язку Resource-до групи документів. |
| `DocumentgroupName` | Іменовані групи документів, які використовуються правилами доступу до Інтернету та менеджера. |
| `FileGroup` | Рядки групи доступу до файлів, пов’язані з групами документів. |

## Моделі елементів

| Модель | Відповідальність |
| --- | --- |
| `SiteTemplate` | Шаблони, призначені ресурсам і підключені до Template Variables. |
| `SiteTmplvar` | Визначення Template Variable: тип, назва, підпис, категорія, елементи, відображення, параметри за замовчуванням і властивості. |
| `SiteTmplvarTemplate` | Відношення та ранг шаблону до TV. |
| `SiteTmplvarContentvalue` | TV значення, збережені для окремих ресурсів. |
| `SiteTmplvarAccess` | TV правила доступу. |
| `SiteHtmlsnippet` | Chunks. Історична назва моделі залишається `SiteHtmlsnippet`. |
| `SiteSnippet` | Snippets і пов’язані з модулем метадані фрагмента. |
| `SitePlugin` | Plugins, код плагіна, властивості, зв’язок модуля, увімкнений/вимкнений стан та альтернативні пошуки плагіна. |
| `SitePluginEvent` | Plugin відношення до події та пріоритет. |
| `SiteModule` | Manager модулі, код модулів/файли ресурсів, спільні параметри та дії запуску/редагування/залежності. |
| `SiteModuleAccess` | Module правила доступу. |
| `SiteModuleDepobj` | Module рядки об’єкта залежності. |
| `Category` | Групування за категоріями для елементів і організації менеджера. |

## Налаштування, події та журнали

| Модель | Відповідальність |
| --- | --- |
| `SystemSetting` | Системні параметри, завантажені середовищем виконання та менеджером. |
| `SystemEventname` | Іменований реєстр подій, підключений до плагінів. |
| `EventLog` | Записи журналу подій. |
| `ManagerLog` | Manager записи журналу активності. |

## Користувачі та дозволи

| Модель | Відповідальність |
| --- | --- |
| `User` | Модель облікового запису користувача Manager/web. |
| `UserAttribute` | Профіль користувача та атрибутивні дані. |
| `UserSetting` | Налаштування для кожного користувача. |
| `UserValue` | Зберігання цінності користувача. |
| `UserRole` | Manager модель для наслідування. |
| `UserRoleVar` | Відношення доступу «роль до TV». |
| `Permissions` | Manager записи дозволів. |
| `PermissionsGroups` | Записи групи дозволів. |
| `RolePermissions` | Рядки зв’язку дозволу на роль. |
| `MemberGroup` | Рядки відношення груп веб-користувачів. |
| `MembergroupAccess` | Рядки відношення доступу до групи учасників. |
| `MembergroupName` | Іменовані групи веб-користувачів. |

## Моделі стану виконання

| Модель | Відповідальність |
| --- | --- |
| `ActiveUser` | Відстеження користувачів активного менеджера. |
| `ActiveUserLock` | Блокування активного редагування. |
| `ActiveUserSession` | Записи активних сеансів менеджера. |
| `SystemCliTask` | Збережені рядки системних завдань для потоків CLI/worker. |
| `SystemCliTaskLog` | Рядки журналу завдань. |
| `SystemSchedulerHealth` | Планувальник медичних книжок. |
| `SystemWorkerHealth` | Медичні книжки працівників. |

## Правило документації

Під час написання детальної документації моделі перевірте файл моделі, зв’язки,
міграції та тести разом. Не виводьте поля лише зі старої документації
або з міток інтерфейсу користувача.
