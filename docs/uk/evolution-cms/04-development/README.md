# Розвиток

[Evolution CMS](../README.md) / Розробка

У цьому розділі пояснюється поточне середовище виконання Evolution CMS із кодової бази
назовні: макет проекту, середовище виконання ядра, поверхні менеджера, точки розширення,
межі пакетів, тести та рівні сумісності.

## Сторінок

| Сторінка | Призначення |
| --- | --- |
| [Структура проекту](project-structure.md) | Відобразіть поточний макет сховища та основні обов’язки під час виконання. |

## Поточний обсяг

Перша сторінка розробки — це вихідна карта. Детально API, модель, подія, послуга,
і довідкові сторінки бази даних є окремою подальшою роботою та мають бути перевірені
проти поточного коду перед публікацією.
