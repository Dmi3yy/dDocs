# Безпека, оновлення та операції

[Evolution CMS](../README.md) / Безпека, оновлення та операції

Цей розділ охоплює операційну сторону поточного проекту Evolution CMS:
діагностика встановлення, оновлення кешу, дозволи, URL-адреси, доступ до файлів,
оновлення та перевірки безпеки виробництва.

## Сторінок

| Сторінка | Призначення |
| --- | --- |
| [Усунення несправностей](troubleshooting.md) | Перший рядок перевіряє загальні проблеми зі встановленням, диспетчером, кеш-пам’яттю, URL-адресою, дозволами та документацією пакетів. |

## Поточний обсяг

Перший прохід додає практичний контрольний список для усунення несправностей. Посилення безпеки,
Сторінки процесу оновлення, резервного копіювання/відновлення, розгортання та моніторингу є подальшими
працювати і перед публікацією має бути перевірено на поточний код.
