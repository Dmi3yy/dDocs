# Вимоги

[Назад](README.md) / [Вгору](README.md) / [Далі](installation.md)

Поточна документація Evolution CMS має описувати середовище виконання, яке існує зараз,
не старіші припущення Evo 1.x із застарілого архіву документів.

## Основне середовище виконання

| Вимога | Поточний базовий рівень |
| --- | --- |
| PHP | `^8.3` |
| Composer | Composer 2.x для встановлення проекту та пакета. |
| Доступ до бази даних | Потрібен PDO. MySQL, PostgreSQL, SQLite і SQL Server підтримуються поточними параметрами інсталятора, якщо доступний відповідний драйвер PHP. |
| PHP розширення | Для Core потрібні JSON, PDO, ZIP, mbstring, розширення, пов’язані з XML, session, tokenizer, OpenSSL, ctype, fileinfo, filter, hash, iconv і PCRE. |
| Додаткова підтримка зображень | GD або Imagick рекомендовано для обробки зображень. |

Кореневий проект `composer.json` є мінімальним, тоді як `core/composer.json` володіє
більший набір залежностей середовища виконання: компоненти Illuminate 12, Flysystem, PHPMailer,
Tracy, Symfony Process, інтеграція Composer і пакети підтримки.

## Виконання інсталятора

Автономний інсталятор вимагає:

| Вимога | Примітки |
| --- | --- |
| PHP | `^8.3` |
| Composer | Необхідний для встановлення глобального інсталятора та налаштування проекту. |
| JSON, PDO, MySQLi, ZIP | Вимагається пакетом інсталятора. |
| GitHub доступ | Необхідний, коли завантажувач завантажує або оновлює двійковий файл інсталятора Go з GitHub Releases. |
| Каталог bin програми встановлення | Необхідний для `evo self-install` і двійкової інсталяції при першому запуску. |

Команда інсталятора `system-status` перевіряє операційну систему, версія PHP,
Драйвери Composer, PDO, JSON, MySQLi, mbstring, cURL, підтримка зображень, дисковий простір,
і обмеження пам'яті.

## Правило документації

Якщо вимога скопійована зі старої документації, звірте її з поточною
Файли Composer, код інсталятора та перевірки інсталяції перед публікацією тут.
