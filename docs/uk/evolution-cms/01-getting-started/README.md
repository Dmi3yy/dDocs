# Початок роботи

[Evolution CMS](../README.md) / Початок роботи

Цей розділ допоможе новим читачам зрозуміти підтримуваний шлях встановлення та
мінімальне середовище, необхідне для поточного проекту Evolution CMS.

## Сторінок

| Сторінка | Призначення |
| --- | --- |
| [Вимоги](requirements.md) | Передумови середовища виконання та інсталятора. |
| [Встановлення](installation.md) | Поточний процес створення проекту встановлювачем. |
| [Основні поняття](core-concepts.md) | Словник продуктів для ресурсів, шаблонів, TVs, блоків, фрагментів, плагінів, подій, модулів, пакетів і Extras. |

## Поточний обсяг

Перше проходження зосереджується на поточному встановленні, вихідних фактах і базовому словнику.
Огляд першого проекту та шляхи оновлення є окремими подальшими завданнями.
