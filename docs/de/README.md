# Dokumentations-Hub

Dieser Dokumentations-Hub trennt die Dokumentation des dDocs-Moduls von der
Produktdokumentation für Evolution CMS.

| Abschnitt | Öffnen |
| --- | --- |
| Evolution CMS | [Evolution CMS Dokumentation](evolution-cms/README.md) |
| dDocs | [dDocs Dokumentation](ddocs/README.md) |

Verwenden Sie die [dDocs Dokumentation](ddocs/README.md) für das Modul, die
Standards der Paketdokumentation, Dateiindizierung, Darstellung, Erstellung und
Beitragsregeln. Die [Evolution CMS Dokumentation](evolution-cms/README.md) enthält
die aktuelle Produktdokumentation aus der Evolution CMS-Codebasis und dem Installer.
