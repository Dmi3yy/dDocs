# Dokumentations-Hub

Dieser deutsche Dokumentations-Hub trennt die dDocs-Moduldokumentation von der
Produktdokumentation für Evolution CMS.

| Bereich | Öffnen |
| --- | --- |
| dDocs | [dDocs Dokumentation](ddocs/README.md) |
| Evolution CMS | [Evolution CMS Dokumentation](evolution-cms/README.md) |

Verwenden Sie die [dDocs Dokumentation](ddocs/README.md) für Modul- und
Paketdokumentationsstandards, Dateiindizierung, Rendering, Authoring und
Beitragsregeln. Verwenden Sie die
[Evolution CMS Dokumentation](evolution-cms/README.md) für die aktuelle
Produktdokumentation aus der Evolution CMS-Codebasis und dem Installer.
