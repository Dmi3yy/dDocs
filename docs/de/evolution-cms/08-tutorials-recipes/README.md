## Rezeptregeln

- Bevorzugen Sie aktuelle Projekt-, Paket-, Routen- und Modelloberflächen.
- Behalten Sie das installierte Extra-Verhalten in den eigenen Dokumenten des Pakets bei.
- Kopieren Sie keine alten Snippets, alten Komponenten oder älteren Installationspfade als aktuell
  Empfehlungen.
- Link zu Referenzseiten, wenn ein Rezept von einem umfassenderen Vertrag abhängt.
